# Kawa Budget Platform

Household budget dashboard for Ajay and Louise. Single-page app, no server.

## Hosting on GitHub Pages
1. Create a repository (private is fine) and upload the contents of this folder to the root.
2. Settings → Pages → Source: *Deploy from a branch*, branch `main`, folder `/ (root)`.
3. Open `https://<user>.github.io/<repo>/` and sign in with the PIN.
4. On a phone, open the page in Safari or Chrome and choose **Add to Home Screen**.

Data (categories, notes, uploaded statements, bills) is stored in the browser on each device.
Use Settings → Backup (JSON) to move it between devices, and Settings → Download Excel for the workbook.
